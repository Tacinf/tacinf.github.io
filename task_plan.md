# Tacinf visual redesign

## Goal
Upgrade the public Tacinf site into a more refined, editorial, design-led experience and deploy the finished static site.

## Phases
- [x] Phase 1 — Audit structure, styles, assets, and deployment path
- [x] Phase 2 — Inspect current rendered page and define visual direction
- [x] Phase 3 — Implement visual redesign and responsive refinements
- [x] Phase 4 — Validate locally and run quality checks
- [x] Phase 5 — Commit and deploy to GitHub Pages
- [ ] Phase 6 — Refine the palette, logo mark, and type pairing from user feedback
- [ ] Phase 7 — Recheck and deploy the visual polish

## Decisions
- Keep the static, dependency-free architecture and existing content/assets.
- Preserve the module tabs, lightbox, videos, and 3D viewer interactions.
- Favor a restrained graphite/ivory palette with a single acid-green accent, stronger editorial grid, and quieter surfaces.
